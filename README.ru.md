<h1 align="center">LipFlow</h1>

Портативный настольный инструмент подготовки видео и синхронизации движений губ с аудио.

Это публичная витрина проекта. Исходники, актуальные сборки и инструкции находятся в [оригинальном репозитории](https://github.com/svllvsxprod/LipFlow). Полная копия исходного README сохранена [здесь](README.md).

**Темы:** `video-processing`, `lip-sync`, `media-tools`
